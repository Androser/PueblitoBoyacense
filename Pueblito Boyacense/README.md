# Propuesta Ecosistema Interactivo — Pueblito Boyacense

Propuesta comercial interactiva para la administración del Pueblito Boyacense.

## Ver la propuesta

Abre el archivo `index.html` en cualquier navegador.

Si activas GitHub Pages o Vercel, la puedes ver en:
`https://androser.github.io/PueblitoBoyacense`

## Chat con IA

El documento incluye un chat integrado que funciona en modo local sin costos.

Para usar una API de IA real (Gemini, OpenAI o Anthropic):
1. Copia `chat-config.example.js` como `chat-config.js`.
2. Coloca tu API key.
3. Recarga la página.

**No subas `chat-config.js` con una API key real.** Ese archivo ya está ignorado en `.gitignore`.

## Cargar contenido de comercios

Usa el archivo `Contenido_Pueblito_Boyacense_simple.xlsx`. Solo tiene 3 hojas para llenar:

1. **Mis Servicios** — una fila por cada servicio o producto.
2. **Preguntas Chatbot** — preguntas frecuentes y respuestas.
3. **Categorías y Manzanas** — listas de apoyo.

Las filas de ejemplo están marcadas en color amarillo; bórralas antes de entregar.
